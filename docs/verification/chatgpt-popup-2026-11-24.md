# ChatGPT 弹窗接入验收

验证日期：2026-11-24（Asia/Singapore）。

正式弹窗已改用 ChatGPT 网页直连。调用保存在 Windows DPAPI 中的当前有效 Chrome 会话，发送前独立完成网页客户端校验，收取并渲染压缩 SSE 消息。实际发送过程中没有打开浏览器页面，也未调用扩展。

## 真实请求

| 场景 | 结果 |
| --- | --- |
| 正式传输模块提问 | 完整返回 `DESKTOP_OK` |
| 弹窗联网搜索 OpenAI 官网地址 | 回答完成并返回官网地址 |
| 在同一会话追问刚才查的网站 | 正确返回 `openai.com` |
| 回答开始后点击停止 | 弹窗结束等待，远端停止请求成功，后台请求退出 |
| 从弹窗发送应用头像 PNG | 上传并发送完成，正确描述紫色背景、星形聊天气泡 |
| 搜索引用显示 | 用真实回答元数据验证，网页 `<Cite>` 标记转换为可读的来源链接 |

输入框发送后清空，答案通过增量事件更新，思考正文保持隐藏。设置中可选择网页账号和该账号提供的模型。当天持续复用会话，跨过本地日期的零点后下一条问题开启新会话。需要查看记录时可主动打开对应网页会话。

## 本机回归检查

网页会话导入和更新、不同账号隔离、压缩回复、完成与中断的区分、来源渲染、每日会话及界面缩放均有离线回归覆盖。错误日志只记录阶段、状态和代码位置，不记录正文、令牌或 Cookie。

程序和校验运行时均存放在项目目录。校验子进程会在后台预生成、每 8 分钟刷新或发送时补充校验时短暂运行，完成或停止后退出。登录凭据和会话位置位于当前 Windows 用户的 `%LOCALAPPDATA%\DesktopAI`，便携包不包含这些个人数据。

本次结果不等于已验证数月连续运行。长期闲置、网页登录生命周期和网页协议升级后的兼容性仍需后续观察。
